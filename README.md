# PassWord-generator
This Program Make only for personal,educational perpose.

## Requirements
- Python 3.x

## Usage
Clone the repository and run:

```bash
python "Password generator.py"
```

Follow the prompts:
1. **Enter Your Name:** (default user: `jahid`)
2. **Enter Your Password:** (default: `12345`)
3. **Enter Your Hints To Make PassWord To generate:**

The tool will output a generated password based on your hint input.
